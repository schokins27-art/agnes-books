# Книга Литы

Добавлена третья книга в стопку: сверху Томми, посередине Лита, снизу Мэгги.

Книга Литы содержит утверждённые переднюю и заднюю обложки и две страницы карты «Архипелаг Забвения» (левую и правую). Дубликаты тех же двух картинок не добавлены повторно.

Открытие, перелистывание, закрытие, звуки и управление используются из общего `library.js` без изменения логики. Для обновления сайта загрузите содержимое архива в корень репозитория с сохранением папок.
