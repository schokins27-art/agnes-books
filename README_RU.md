# Book of Tommy — обновлённая версия

## Как обновить сайт

1. Открой свой репозиторий `agnes-books` на GitHub.
2. Загрузи **содержимое** этой папки в корень репозитория, заменяя старые файлы: `index.html`, `style.css`, `script.js` и `books/tommy/*`.
3. Для загрузки папки `books/tommy` проще использовать GitHub Desktop или перетащить всю структуру в интерфейс Upload files (с сохранением путей). Убедись, что файл `books/tommy/book.json` лежит именно там.
4. Нажми Commit changes. Подожди завершения Pages deployment во вкладке Actions.
5. Открой прежний адрес GitHub Pages и обнови страницу через Ctrl+F5. В tldraw обнови встроенный элемент.

## Универсальный шаблон

Для другой книги создай `books/eric/`, положи `cover.webp`, `back.webp`, `page-01.webp`, `page-02.webp` и т. д., а также `book.json` по образцу `books/tommy/book.json`. Страницы перечисляются в порядке чтения; каждые две становятся разворотом.

Ссылка на новую книгу: `https://ВАШ-ЛОГИН.github.io/agnes-books/?book=books/eric/book.json`.

## Замечания

Семейная фотография и снимок детей вырезаны из предоставленного PDF, а не перегенерированы. Текст восстановлен из PDF и перерисован читаемым курсивным шрифтом; он не имитирует точный почерк. Перелистывание — 3D-анимация на CSS, а не физическая симуляция изгиба листа.
